# Evaluation for DH2408: Evaluation Methods in Human-Computer Interaction (6.0 ECTS)

**Course Evaluation: DH2408**

**Criteria Breakdown**

1. **Autodidact Threshold**
	* Pass: High theoretical density
	* Fail: Tool-, API-, or documentation-heavy
	* Result: **Fail** (material easily learned via official docs, GitHub, or online tutorials)
2. **Essential Knowledge in Industry**
	* Value for high-skill ceiling engineering/research roles
	* Result: **Moderate** (relevant to industry, but not necessarily essential for high-skill roles)
3. **Prerequisite Knowledge**
	* Essential foundational material early on
	* High if it covers 80% of what's needed to know
	* Result: **Low** (not essential foundational material; doesn't cover the majority of required knowledge)
4. **Frequently used on the job**
	* Core skill used daily or occasionally
	* Result: **Moderate** (used occasionally, but not necessarily a core skill for day-to-day work)

**Strategic Takeaway:** This course is suitable for engineers/researchers with a moderate need to apply its knowledge in industry settings, and can be considered a supplement to existing skills rather than foundational material.
