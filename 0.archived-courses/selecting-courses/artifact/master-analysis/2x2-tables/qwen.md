# KTH MSc Applied Mathematics - Course Strategy & Categorization

## Strategic Evaluation: Which combination gives you more advantage?

**Verdict: Low Autodidactical + High Industrial provides a significantly higher advantage.**

*   **The "Moat" and Signaling Effect:** Because "Low Autodidactical" courses require deep conceptual understanding and deliberate study, they act as a natural filter. Employers know you didn't just copy-paste from well-documented tutorials. You had to grapple with the underlying math.
*   **Portfolio > Free Time:** "High Autodidactical" courses give you more free time because the material is easy to pick up. However, if they are "Low Industrial," they don't help you build a portfolio. Free time is only an advantage if you have the extreme self-discipline to use it to build side projects. 
*   **Industry Reality:** High-paying roles for Applied Math graduates at KTH (Machine Learning Engineer, Quantitative Researcher, Operations Research Scientist) do not care how fast you can read documentation. They care about your ability to model complex, real-world problems.

**Bottom-Line Strategy:** Stack Low-Autodidactical / High-Industrial courses (e.g., Compilers + Advanced Algorithms) to build a "prestige combo" for Big-N interviews. Counterbalance this heavy cognitive load explicitly with named project courses from the High/High quadrant (e.g., Project Course in Data Science) to act as free-time generators and automatically output GitHub repositories.
