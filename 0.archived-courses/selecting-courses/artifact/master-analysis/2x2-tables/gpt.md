## 2x2 Strategic Matrix

| | High Industrial (Employable) | Low Industrial (Academic) |
| :--- | :--- | :--- |
| **High Autodidactic** <br>*(Fast Tech/Tools)* | **Quadrant A: The Time Savers**<br>• SF2526, SF2525, SF2565 (Numerics/C++)<br>• DD2421, DD2434, DD2257 (ML/Vis)<br>• SF2930, SF2943, SF2935 (Stats) | **Quadrant B: The Multipliers**<br>• DD2440, DD2445, SF2956 (Algo/Topology)<br>• SF2741, SF1677, SF1678, SF1691 (Pure Math)<br>• SF2971, SF2940 (Stochastics/Probability) |

**Strategic Target:** Aim for A (30-40%), C (30-40%), B (20-30%), D (0-10%). 
Once your exposure to Quadrant C (expensive-to-acquire industrial skills) is strong, Quadrant B becomes highly valuable for conceptual breadth that boosts your performance in C, while Quadrant A is the dominant choice for efficiently producing portfolio artifacts.

# Course Categorization: KTH Computer Science MSc (TCSCM)

## 2x2 Strategic Matrix

| | High Industrial (Employable) | Low Industrial (Academic) |
| :--- | :--- | :--- |
| **High Autodidactic** <br>*(Fast Tech/Tools)* | **Quadrant A: The Time Savers**<br>• DD2380, DD2421, DD2424, DD2430, DD2437 (AI/Data)<br>• DD2480, DD2482, DD2489, DD2529, ID1217 (Software Eng)<br>• DD2360, DD2375, IK2221, ID2223 (HPC/Systems)<br>• DD2257, DH2322, DH2310, DH2650 (Graphics/Vis) | **Quadrant B: The Multipliers**<br>• DD2585 (Blockchains/Smart Contracts)<br>• DM2730 (Tech Enhanced Learning)<br>• DD2367, DD2368, DD2366 (Quantum Computing) |
| **Low Autodidactic** <br>*(Hard Theory)* | **Quadrant C: The Core Asset**<br>• DD2395, DD2459, DD2460, DD2525, DD2528 (Security)<br>• IK2218, DD2358, DD2443, ID2202, IK2215 (Systems/Dist)<br>• DD2440, DD2452, DD2557, DD2481 (Algorithms/PL) | **Quadrant D: The Niche**<br>• SF2740, SF2972, SF2940 (Math Theory)<br>• DD2542, DD2445, DD2552, DD2467 (Theoretical CS Seminars)<br>• DH2632 (HCI Research Seminars) |

**Strategic Target:** Aim for A (30-40%), C (30-40%), B (20-30%), D (0-10%).
TCSCM is unusually rich in Quadrant A. Capitalize on these to generate strong software and system portfolio artifacts without draining all independent project capacity. Use Quadrant C to acquire systems/security fundamentals that are hard to learn alone.
