# KTH Applied Mathematics MSc – Course Categorization

**Interpretation of axes:**
- **High industrial** = directly useful for industry roles.
- **Low industrial** = more academic/theoretical, less directly applicable to typical industry jobs.
- **Low autodidactal** = hard to learn on your own; requires structured study and conceptual depth.
- **High autodidactal** = can be picked up from documentation, projects, and practice.

|                        | Low autodidactal | High autodidactal |
|------------------------|------------------|-------------------|
| **High industrial**    | Finite Element Method, Optimal Control, Financial Mathematics I & II, Systems Engineering, Applied Nonlinear Optimization, Parallel Computations | Program Construction in C++ for Scientific Computing, Modern Methods of Statistical Learning, Applied Linear Optimization, Financial Derivatives, Risk Management, Applied Numerical Methods |
| **Low industrial**     | Probability Theory, advanced PDE theory, Lie Groups/Algebras, proof-heavy numerical analysis | Matrix Computations, Statistical Inference, some numerical analysis/statistics electives |

---

### Practical priority for industry-oriented students:
1. **Low autodidactal + High industrial** – highest value, hardest to self-study.
2. **High industrial + High autodidactal** – good for portfolio/free time, but self-learnable.
3. **Low industrial + Low autodidactal** – only for PhD/academic depth.
4. **Low industrial + High autodidactal** – weakest use of credits for industry.

# KTH Computer Science MSc (TCSCM) – Course Categorization

**Interpretation of axes:**
- **High industrial** = directly useful for industry roles.
- **Low industrial** = more academic/theoretical, less directly applicable to typical industry jobs.
- **Low autodidactal** = hard to learn on your own; requires structured study and conceptual depth.
- **High autodidactal** = can be picked up from documentation, projects, and practice.

|                        | Low autodidactal | High autodidactal |
|------------------------|------------------|-------------------|
| **High industrial**    | Advanced algorithms, distributed systems & consistency, computer security / applied crypto, compiler construction, concurrent/parallel programming, program analysis / formal verification, advanced ML theory, network algorithms, safety-critical systems | Web development, mobile applications, database systems, data-intensive computing, cloud computing, big data, applied ML/deep learning with frameworks, information visualization, software engineering / agile / DevOps, software testing, requirements engineering |
| **Low industrial**     | Theory of computation, programming language theory / type theory, formal semantics, mathematical logic, automata theory, advanced complexity theory, quantum computing (if offered) | Basic scripting/tooling courses, introductory database/web courses (if already known), niche language electives, simple data-structure refreshers |

---

### Practical priority for industry-oriented students:
1. **Low autodidactal + High industrial** – hardest to self-study, directly valued by employers.
2. **High industrial + High autodidactal** – good for portfolio/teamwork, but self-learnable.
3. **Low industrial + Low autodidactal** – mainly for research or specialized roles.
4. **Low industrial + High autodidactal** – usually a weak use of credits unless prerequisites require it.
